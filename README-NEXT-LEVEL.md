## 🚀 **INSTALLATION**

### **1. Install Dependencies**
```bash
cd portfolio-app-NEXT-LEVEL
npm install
```

### **2. Environment Variables**
Create `.env`:
```bash
DATABASE_URL="postgresql://..."
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="din-secret-key-her"
```

### **3. Database Setup**
```bash
npx prisma generate
npx prisma db push
npx prisma db seed
```

### **4. Run Dev Server**
```bash
npm run dev
```

Besøg: `http://localhost:3000`
