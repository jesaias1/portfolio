# ⚡ QUICK START - 5 MINUTTER TIL LIVE!

## 🚀 **ULTRA HURTIGT SETUP**

### **Step 1: Install (2 min)**
```bash
cd portfolio-app-NEXT-LEVEL
npm install
```

### **Step 2: Environment (.env)**
```bash
DATABASE_URL="din-database-url"
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="generer-en-random-string"
```

### **Step 3: Database (1 min)**
```bash
npx prisma generate
npx prisma db push
npx prisma db seed
```

### **Step 4: Run! (10 sec)**
```bash
npm run dev
```

**BOOM! 💥 Åbn http://localhost:3000**

---

## 🌐 **DEPLOY TIL VERCEL (5 MIN)**

### **1. Push til GitHub:**
```bash
git init
git add .
git commit -m "🚀 Next-level portfolio"
git remote add origin https://github.com/jesaias1/portfolio.git
git push -u origin main
```

### **2. Vercel:**
1. Gå til vercel.com
2. "Import Project"
3. Vælg dit GitHub repo
4. Add environment variables (DATABASE_URL, NEXTAUTH_URL, NEXTAUTH_SECRET)
5. Deploy!

**LIVE PÅ 5 MIN! 🎉**
